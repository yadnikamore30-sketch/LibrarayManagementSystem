PROJECT TITLE
Library Management System

OBJECTIVE
To develop a Java-based Library Management System that helps manage books,
readers, book issuing, book returns, and report generation efficiently.

MODULES

1. Login Module
   - Staff/Admin login

2. Book Management Module
   - Add Book
   - Update Book
   - Delete Book
   - View Books

3. Reader Management Module
   - Add Reader
   - Update Reader
   - Delete Reader
   - View Readers

4. Issue Book Module
   - Issue books to readers
   - Store issue details

5. Return Book Module
   - Return issued books
   - Update availability

6. Search Module
   - Search books
   - Search readers

7. Reports Module
   - Issued books report
   - Returned books report
   - Available books report

TECHNOLOGIES USED

- Java
- Swing
- MySQL
- JDBC
